# Society Documents

Each subfolder here is a **category** that shows up on the website's Documents page.

## How to add a document (manager workflow)

1. Open the right category folder on GitHub.
2. Click **Add file → Upload files**.
3. Drag the PDF (or DOCX) in.
4. **Important:** name the file the way you want it to appear on the site.
   - Good: `AGM Minutes - 8 March 2026.pdf`
   - Bad: `agm.pdf`, `Scan_001.pdf`
   - Use spaces, capital letters, dates — whatever you want residents to see.
5. Click **Commit changes**. The site updates automatically (~30s).

## How to add a new category

Create a new subfolder in this `Document/` directory. The folder name becomes the category heading on the website.

## How to remove a document

Open the file on GitHub, click the trash icon, **Commit changes**.
