# Notices

> Edit this file to update the Notice Board on the website.
>
> **How it works**
> - Each `## Heading` starts a new notice card.
> - Optional metadata can go right under the heading using `key: value` lines (no blank line between heading and metadata).
> - After metadata, leave one blank line, then write the description.
> - End with `> [Button label](https://link.example.com)` to add a call-to-action button.
> - Mark a notice as urgent by adding `urgent: true` in metadata.
